# RisuNest Sync v1.0.4

## English

- Improved Windows setup, updates, and removal so interrupted operations can be retried.
- Fixed update checks to compare against the installed bundle version, and fixed reinstalling when the installation folder is missing.
- Existing x64 installations on ARM64 Windows continue receiving x64 updates.
- Fixed GUI profile cleanup during removal and cleared temporary notices consistently.

## 한국어

- Windows 설치, 업데이트, 제거가 중단된 경우 다시 시도할 수 있도록 개선했습니다.
- 설치된 번들 버전을 기준으로 업데이트를 확인하며, 설치 폴더가 없는 경우의 재설치 문제를 수정했습니다.
- ARM64 Windows의 기존 x64 설치는 x64 업데이트를 계속 받을 수 있습니다.
- 제거 시 GUI 프로필 정리와 임시 알림 표시 문제를 수정했습니다.
