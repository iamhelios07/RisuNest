# RisuNest v1.0.6

## English

- Fixed RisuAI account backup and restore not working.
- Fixed restore problems with some backup files and improved restore failure notices.
- Fixed backup and sync issues with external storage such as Google Drive, OneDrive, and GitHub.
- Added a UI and popups that show sync status and errors.
- Added a feature that delays loading plugins until sync has fully finished (prevents plugin data corruption).
- Fixed and improved Sync server synchronization.
- Added CBS parsing for plugins (parseRisuChat).
- Improved plugin storage compatibility (fixed storing Date objects).
- Improved conversation loading performance with long chats or many assets.
- Fixed bugs in automatic input translation, toggle presets, and lorebooks.
- Fixed a bug that could navigate the RisuNest app to an external page.
- Fixed and improved file downloads on all platforms, including plugin file downloads.
- Improved the Windows installer.
- Improved error messages and logging.

## 한국어

- RisuAI 계정 백업 및 복원이 동작하지 않던 문제 수정.
- 일부 파일의 백업 복원 문제 수정 및 복원 실패 안내 개선.
- Google Drive, OneDrive, GitHub 등 외부 저장소 백업 및 동기화 문제 수정.
- 동기화 상태, 오류 등을 표시하는 UI와 팝업창 추가.
- 동기화가 모두 끝날 때까지 플러그인 로딩을 지연시키는 기능 추가(플러그인 데이터 손상 방지).
- Sync 서버 동기화 로직 수정 및 개선.
- 플러그인 CBS 해석 기능(parseRisuChat) 추가.
- 플러그인 저장소 호환성 개선(Date 객체 저장 문제 수정).
- 채팅이 많거나 에셋이 많은 경우 대화 로딩 성능 개선.
- 입력 자동 번역, 토글 프리셋, 로어북 관련 버그 수정.
- RisuNest 앱 내에서 외부 페이지로 나갈 수 있던 버그 수정.
- 모든 플랫폼에서 파일 다운로드 기능 수정 및 개선(플러그인 파일 다운로드 포함).
- Windows 설치 프로그램 개선.
- 오류 표현 및 로깅 개선.
