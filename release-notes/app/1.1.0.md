# RisuNest v1.1.0

## English

- Applied RisuAI v2026.10.211 changes.
- Added asset and inlay (chat attachment) galleries.
- Expanded image format support for personas, character icons, and more.
- Improved tasks such as responses and sync to keep running after leaving the app on mobile.
- Added progress and resuming to RisuAI account restores and improved their performance.
- Fixed external storage sync showing as complete before it had finished.
- Optimized memory usage when sending messages in long chats.
- Fixed compatibility issues in some Lua modules (such as Lightboard).
- Fixed a bug where the built-in translator could send translation requests repeatedly.
- Fixed clock and server connection issues in external storage and Sync synchronization.
- Fixed PocketRisu exports not working with some settings.
- Fixed asset bot downloads from Realm and CharX imports not working properly.
- Replaced the Gemini/Gemma tokenizer with the Gemma 4 tokenizer.
- Added a setting for the scroll navigation buttons.
- Changed update checks to run at every app start.
- Improved overall performance of storage, backups, restores, sync, rendering, and startup.
- Improved error messages and logging.

## 한국어

- RisuAI v2026.10.211 변경 사항 반영.
- 에셋 및 인레이(채팅 첨부) 갤러리 추가.
- 페르소나, 캐릭터 아이콘 등 이미지 포맷 지원 확대.
- 모바일에서 앱을 벗어나도 응답이나 동기화 등의 작업이 계속 진행되도록 개선.
- RisuAI 계정 복원 진행률 표시 및 이어받기 기능 추가, 성능 개선.
- 외부 저장소 동기화가 완료되지 않았는데 완료로 표시되던 문제 수정.
- 긴 채팅에서 메시지 전송 시 메모리 사용량 최적화.
- 일부 Lua 모듈(Lightboard 등)에서 발생하던 호환성 문제 수정.
- 내장 번역 기능에서 번역 요청이 반복 전송될 수 있던 버그 수정.
- 시간, 서버 접속 관련 외부 저장소 및 Sync 동기화 문제 수정.
- 설정에 따라 PocketRisu 내보내기가 동작하지 않던 문제 수정.
- Realm의 에셋 봇 다운로드나 CharX 임포트가 제대로 동작하지 않던 문제 수정.
- Gemini/Gemma 토크나이저를 Gemma 4 토크나이저로 교체.
- 스크롤 네비게이션 버튼 UI 설정 추가.
- 앱을 시작할 때마다 업데이트를 확인하도록 변경.
- 저장, 백업/복원, 동기화, 렌더링, 앱 시작 등 전반적인 성능 향상.
- 오류 표현 및 로깅 개선.
