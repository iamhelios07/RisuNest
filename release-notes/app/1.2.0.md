# RisuNest v1.2.0

## English

### Breaking Changes

- The sync data format of the Sync server and external storage changes (Sync server update required). After updating every device, switch the format in the sync settings; after the switch, only the same or newer versions can sync with each other.

### New Features

- Added an app lock (if you forget the PIN, you may need to restore your data from a backup).
- Added author's note presets.
- Added binary data support to plugin local storage (getLocalPluginStorage).
- Added a separate permission for plugin tool calls.
- Added a setting that sends only the current chat to plugins (reduces memory usage).

### Improvements

- Changed deleting a character, module, or similar item to also delete its assets.
- Responses being generated are now kept if the app closes.
- Added execution time limits to regex scripts and triggers, and made Lua stop properly on timeout (prevents endless loading).
- Changed desktop downloads to ask for a save location.
- Removed the Keep Session Alive setting (a web-only feature).
- Changed Lua scripts to run in a Worker and CBS to run compiled.
- Improved performance and memory usage of regex, rendering, lorebooks, storage, restores, and more.
- Improved error messages and logging.

### Fixes

- Fixed plugins not loading when the Sync server is unavailable.
- Fixed messages updated by Lua scripts not re-rendering and chat variables not being saved.
- Fixed CSS and plugins that work with the chat screen not finding chat content.
- Fixed YouTube embeds not playing.
- Fixed Google Translate failures and content that could disappear when translation failed.
- Fixed issues with RisuAI account restores and PocketRisu restores.
- Fixed RisuAI/PocketRisu compatible exports failing.
- Fixed Separate Parameters overwriting saved values.
- Fixed S3 and GitHub external storage sync issues.

## 한국어

### 호환성 변경

- Sync 서버 및 외부 저장소의 동기화 데이터 형식이 변경됩니다(Sync 서버 업데이트 필요). 모든 기기를 업데이트한 후 동기화 설정에서 형식을 전환해야 하며, 전환 이후에는 동일하거나 더 높은 버전끼리만 동기화가 가능합니다.

### 새 기능

- 앱 잠금 기능 추가(PIN을 잊은 경우 백업에서 데이터를 복원해야 할 수 있습니다).
- 작가의 노트 프리셋 추가.
- 플러그인 로컬 저장소(getLocalPluginStorage)에 바이너리 데이터 지원 추가.
- 플러그인 도구 호출에 대한 별도 권한 추가.
- 플러그인에 현재 채팅 기록만 전달하는 설정 추가(메모리 사용량 감소).

### 개선

- 캐릭터나 모듈 등 삭제 시 에셋도 같이 삭제되도록 변경.
- 응답 생성 중 앱이 종료되더라도 내용이 남도록 개선.
- 정규식, 트리거 실행 시간 제한 추가 및 Lua가 시간 초과 시 제대로 중단되도록 개선(무한 로딩 방지).
- 데스크톱에서 다운로드할 때 저장 위치를 선택하도록 변경.
- 세션 유지 설정 제거(웹 전용 기능).
- Lua 스크립트를 Worker에서 실행하고 CBS를 컴파일해 실행하도록 개선.
- 정규식, 렌더링, 로어북, 저장, 복원 등 성능 및 메모리 사용량 개선.
- 오류 표현 및 로깅 개선.

### 수정

- Sync 서버를 사용할 수 없을 때 플러그인을 불러오지 못하던 문제 수정.
- Lua 스크립트로 갱신한 메시지가 다시 렌더링되지 않거나 채팅 변수가 저장되지 않던 문제 수정.
- 채팅 화면에 관여하는 CSS나 플러그인이 채팅을 제대로 찾지 못하던 문제 수정.
- YouTube 임베드가 재생되지 않던 문제 수정.
- Google 번역 실패 및 번역 실패 시 내용이 사라질 수 있던 문제 수정.
- RisuAI 계정 복원 및 PocketRisu 복원 관련 문제 수정.
- RisuAI/PocketRisu 호환 내보내기에 실패하던 문제 수정.
- 파라미터 분리 설정이 저장된 값을 덮어쓰던 문제 수정.
- S3, GitHub 외부 저장소 동기화 문제 수정.
