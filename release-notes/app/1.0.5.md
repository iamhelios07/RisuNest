# RisuNest v1.0.5

## English

- Added desktop launch profiles and improved Windows install, update, and removal recovery. x64 installations on ARM64 Windows keep receiving x64 updates.
- Added a browser RisuAI backup exporter with folder and preset images. It skips unrestorable items.
- Fixed encrypted RisuAI imports and backups with unset plugin storage. Errors no longer include decoded save contents.
- Improved progress and cancellation for mobile backups, restore preparation, and external-storage connections.
- Removed compatible `.bin` backup limits on total asset count and combined filenames. Fixed restoration of large character fields and messages.
- PNG cards support 50,000 embedded assets and 10 GiB total, retaining the 64 MiB per-asset limit.
- Device plugin storage accepts 512 MiB, measured as the UTF-8 bytes of the JSON-encoded stored string.
- Backups and snapshots with device plugin values above 8 MiB require this version or later. Update every device sharing local plugin data before storing large values: earlier versions can receive them but cannot create device backups or snapshots while they are present.
- Character archives and compatible exports reject oversized data before creating unrestorable files. Import/export size errors identify the data type.
- Added Voyage Context 4 embeddings and fixed batching and compatible exports.
- Fixed anonymous HTML exports, translated HTML export filtering, toggle binding edits, preset overrides, and native chat scroll anchoring.
- Fixed external-storage metadata lookup and upload reconciliation across long GitHub release histories.

## 한국어

- 데스크톱 실행 프로필을 추가하고 Windows 설치·업데이트·제거의 복구를 개선했습니다. ARM64 Windows의 x64 설치는 x64 업데이트를 계속 받습니다.
- 폴더·프리셋 이미지를 포함하는 RisuAI 백업용 브라우저 도구를 추가했습니다. 복원할 수 없는 항목은 건너뜁니다.
- 암호화된 RisuAI 백업과 플러그인 저장소가 설정되지 않은 백업의 복원 문제를 수정했습니다. 백업 오류에 디코딩된 저장 내용이 포함되지 않도록 수정했습니다.
- 모바일 백업 복사, 복원 준비, 외부 저장소 연결의 진행 표시와 취소 처리를 개선했습니다.
- 호환 `.bin` 백업 복원 시 전체 에셋 개수와 파일 이름의 합계 크기 제한을 제거했습니다. RisuNest, RisuAI, PocketRisu에서 저장한 큰 캐릭터 필드와 메시지의 복원 문제를 수정했습니다.
- PNG 캐릭터 카드에 에셋을 최대 50,000개, 합계 10 GiB까지 포함할 수 있습니다. 에셋 하나의 크기 제한은 기존과 같은 64 MiB입니다.
- 기기 플러그인 저장소에 값을 최대 512 MiB까지 저장할 수 있습니다. 크기는 저장할 문자열을 JSON으로 인코딩한 UTF-8 바이트를 기준으로 계산합니다.
- 8 MiB를 초과하는 기기 플러그인 값이 포함된 백업과 스냅샷은 이 버전 이상에서 복원할 수 있습니다. 로컬 플러그인 데이터를 동기화하는 경우 큰 값을 저장하기 전에 참여하는 모든 기기를 업데이트해주세요. 이전 버전에서는 해당 값을 수신할 수 있지만, 값이 있는 동안 기기 백업과 스냅샷을 생성할 수 없습니다.
- 복원할 수 있는 크기를 초과하는 캐릭터 아카이브와 호환 백업 내보내기는 크기 오류로 중단됩니다. 가져오기와 내보내기의 크기 오류에 해당 데이터 종류를 표시합니다.
- Voyage Context 4 임베딩을 지원하며, 배치 처리와 호환 백업 내보내기를 수정했습니다.
- 익명 HTML 내보내기, 번역된 HTML 내보내기의 필터링, 토글 바인딩 편집, 프리셋 적용, 네이티브 채팅 스크롤 유지 문제를 수정했습니다.
- GitHub 릴리즈가 많은 외부 저장소의 메타데이터 조회와 업로드 확인 문제를 수정했습니다.
