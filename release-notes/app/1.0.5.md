# RisuNest v1.0.5

## English

- Fixed failures when restoring RisuAI and PocketRisu backups.
- Fixed large backups failing to restore on Android.
- Fixed backups with 200,000 or more assets failing to restore.
- Improved backup restores and Sync/external storage restores to show progress.
- Improved restore and sync performance.
- Fixed toggle changes being saved automatically when using toggle binding.
- Fixed the scroll position jumping when message heights change.
- Added support for Voyage Context 4 embeddings.
- Raised the local plugin storage limit.
- Fixed file selection not working properly on iOS.
- Improved AltStore integration on iOS and fixed signatures not being passed to the IPA file.
- Added multiple profiles on desktop through `--profile=<name>`.
- Added multiple languages and an architecture check to the Windows installer.
- Improved automatic updates, installation, and removal on Windows.

## 한국어

- RisuAI, PocketRisu 백업 복원에 실패하던 문제 수정.
- Android에서 용량이 큰 백업을 복원하지 못하던 문제 수정.
- 20만개 이상의 에셋을 가진 백업을 복원하지 못하던 문제 수정.
- 백업 복원 및 Sync/외부 저장소 복원 과정에서 진행률 볼 수 있도록 개선.
- 복원 및 동기화 성능 개선.
- 토글 바인드를 사용하는 경우 자동 저장되지 않도록 수정.
- 메시지 높이가 변화할 때 스크롤이 튀던 문제 수정.
- Voyage Context 4 임베딩 지원 추가.
- 로컬 플러그인 저장소 한도 상향.
- iOS에서 파일 선택 기능이 제대로 동작하지 않던 문제 수정.
- iOS AltStore 연동 개선 및 ipa 파일에 서명이 전달되지 않던 문제 수정.
- 데스크톱에서 `--profile=<이름>`으로 멀티 프로필을 사용할 수 있는 기능 추가.
- Windows 설치 파일에 다국어 추가 및 아키텍처 확인 절차 추가.
- Windows에서 자동 업데이트 방식 개선 및 설치/삭제 방식 개선.
