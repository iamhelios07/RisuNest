# RisuNest v1.0.5

## English

- Removed the total asset-entry count and combined filename-size limits when restoring compatible `.bin` backups.
- Fixed restoring large character fields and messages saved by RisuNest, RisuAI, and PocketRisu.
- PNG character cards now support up to 50,000 embedded assets and 10 GiB in total, with the existing 64 MiB limit per asset.
- Device plugin storage now accepts values up to 512 MiB, measured as the UTF-8 bytes of the JSON-encoded stored string.
- Backups and snapshots containing device plugin values larger than 8 MiB require this version or later. When syncing local plugin data, update every participating device before storing large values. Earlier versions can receive them but cannot create device backups or snapshots while those values are present.
- Oversized character archives and compatible backup exports now stop with a size error before producing an archive that cannot be restored. Import and export size failures display the affected data type.

## 한국어

- 호환 `.bin` 백업 복원 시 전체 에셋 개수와 파일 이름의 합계 크기 제한을 제거했습니다.
- RisuNest, RisuAI, PocketRisu에서 저장한 큰 캐릭터 필드와 메시지를 복원하지 못하던 문제를 수정했습니다.
- PNG 캐릭터 카드에 에셋을 최대 50,000개, 합계 10 GiB까지 포함할 수 있습니다. 에셋 하나의 크기 제한은 기존과 같은 64 MiB입니다.
- 기기 플러그인 저장소에 값을 최대 512 MiB까지 저장할 수 있습니다. 크기는 저장할 문자열을 JSON으로 인코딩한 UTF-8 바이트를 기준으로 계산합니다.
- 8 MiB를 초과하는 기기 플러그인 값이 포함된 백업과 스냅샷은 이 버전 이상에서 복원할 수 있습니다. 로컬 플러그인 데이터를 동기화하는 경우 큰 값을 저장하기 전에 참여하는 모든 기기를 업데이트해주세요. 이전 버전에서는 해당 값을 수신할 수 있지만, 값이 있는 동안 기기 백업과 스냅샷을 생성할 수 없습니다.
- 복원할 수 있는 크기를 초과하는 캐릭터 아카이브와 호환 백업 내보내기는 크기 오류로 중단됩니다. 가져오기와 내보내기의 크기 오류에 해당 데이터 종류를 표시합니다.
