# RisuNest v1.0.5

## English

- Added separate desktop launch profiles and improved Windows installation, update, and removal recovery. Existing x64 installations on ARM64 Windows continue receiving x64 updates.
- Added a standalone browser tool for exporting RisuAI backups, including folder and preset images. Unrestorable items are skipped so the remaining data can be exported.
- Fixed encrypted RisuAI backup imports and restoration of backups with unset plugin storage. Backup errors no longer include decoded save contents.
- Improved progress reporting and cancellation while copying mobile backups, preparing restores, and connecting external storage.
- Removed the total asset-entry count and combined filename-size limits when restoring compatible `.bin` backups. Fixed restoring large character fields and messages saved by RisuNest, RisuAI, and PocketRisu.
- PNG character cards now support up to 50,000 embedded assets and 10 GiB in total, with the existing 64 MiB limit per asset.
- Device plugin storage now accepts values up to 512 MiB, measured as the UTF-8 bytes of the JSON-encoded stored string.
- Backups and snapshots containing device plugin values larger than 8 MiB require this version or later. When syncing local plugin data, update every participating device before storing large values. Earlier versions can receive them but cannot create device backups or snapshots while those values are present.
- Oversized character archives and compatible backup exports now stop with a size error before producing an archive that cannot be restored. Import and export size failures display the affected data type.
- Added Voyage Context 4 embeddings and corrected their batching and compatible backup export behavior.
- Fixed anonymous HTML exports, translated HTML export filtering, toggle binding edits, preset overrides, and native chat scroll anchoring.
- Fixed external-storage metadata lookup and upload reconciliation across long GitHub release histories.

## 한국어

- 데스크톱 실행 프로필을 추가하고 Windows 설치, 업데이트, 제거 실패 후 복구를 개선했습니다. ARM64 Windows의 기존 x64 설치는 x64 업데이트를 계속 받을 수 있습니다.
- 폴더와 프리셋 이미지를 포함해 RisuAI 백업을 내보내는 별도 브라우저 도구를 추가했습니다. 복원할 수 없는 항목은 건너뛰고 나머지 데이터를 내보낼 수 있습니다.
- 암호화된 RisuAI 백업과 플러그인 저장소가 설정되지 않은 백업의 복원 문제를 수정했습니다. 백업 오류에 디코딩된 저장 내용이 포함되지 않도록 수정했습니다.
- 모바일 백업 복사, 복원 준비, 외부 저장소 연결의 진행 표시와 취소 처리를 개선했습니다.
- 호환 `.bin` 백업 복원 시 전체 에셋 개수와 파일 이름의 합계 크기 제한을 제거했습니다. RisuNest, RisuAI, PocketRisu에서 저장한 큰 캐릭터 필드와 메시지의 복원 문제를 수정했습니다.
- PNG 캐릭터 카드에 에셋을 최대 50,000개, 합계 10 GiB까지 포함할 수 있습니다. 에셋 하나의 크기 제한은 기존과 같은 64 MiB입니다.
- 기기 플러그인 저장소에 값을 최대 512 MiB까지 저장할 수 있습니다. 크기는 저장할 문자열을 JSON으로 인코딩한 UTF-8 바이트를 기준으로 계산합니다.
- 8 MiB를 초과하는 기기 플러그인 값이 포함된 백업과 스냅샷은 이 버전 이상에서 복원할 수 있습니다. 로컬 플러그인 데이터를 동기화하는 경우 큰 값을 저장하기 전에 참여하는 모든 기기를 업데이트해주세요. 이전 버전에서는 해당 값을 수신할 수 있지만, 값이 있는 동안 기기 백업과 스냅샷을 생성할 수 없습니다.
- 복원할 수 있는 크기를 초과하는 캐릭터 아카이브와 호환 백업 내보내기는 크기 오류로 중단됩니다. 가져오기와 내보내기의 크기 오류에 해당 데이터 종류를 표시합니다.
- Voyage Context 4 임베딩을 지원하며, 배치 처리와 호환 백업 내보내기를 수정했습니다.
- 익명 HTML 내보내기, 번역된 HTML 내보내기의 필터링, 토글 바인딩 편집, 프리셋 적용, 네이티브 채팅 스크롤 유지 문제를 수정했습니다.
- GitHub 릴리즈가 많은 외부 저장소의 메타데이터 조회와 업로드 확인 문제를 수정했습니다.
